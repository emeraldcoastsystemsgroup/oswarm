# Application contracts

Per-application contracts the kernel enforces for store packages. Application code lives in
the store repositories; these pages say what a manifest may declare and what the kernel does
with it.

| --- | --- |

| [motion-native-integrations.md](./motion-native-integrations.md) | Original-owner engine runs, the native artifact exchange, typed Motion transfer and render profiles, and the Video consumer. |
| [../reference/application-dependencies.md](../reference/application-dependencies.md) | Dependencies, composite roles, and the `extends` add-on data namespace. |
