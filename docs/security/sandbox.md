# Sandbox and namespace policy

The kernel container runs as UID 10001, drops every capability, has a read-only root, and delegates each application to Bubblewrap with private PID, network, mount and user namespaces. Children clear the environment, disable further user namespaces, and drop all capabilities. An application mount, such as Career's, contains one admitted person's staged generation and that tenant's read-only job corpus. It never mounts every user's files into a shared package process.

`seccomp-bwrap.json` derives from Moby's [default profile](https://github.com/moby/profiles/blob/main/seccomp/default.json). Only `clone`, `clone3`, `unshare`, `setns`, `mount`, `umount2` and `pivot_root` receive unconditional permission for unprivileged namespace setup. Other default restrictions remain. `systempaths=unconfined` permits the new namespace's `/proc` mount; the outer daemon still has no capabilities or writable host-system mount.

The existing host AppArmor `oshal-bwrap` profile permits user namespace creation. Compose selects that profile for this container. Global host restrictions are retained. A missing host profile causes deployment to fail; there is no privileged or unsandboxed fallback.

The runtime image pins Node 24.21.0, including native `node:sqlite`. The container binds only a loopback address and uses durable state for ledger recovery and the mesh journal. Supply private credentials through `OSHAL_ENV_FILE`; never commit that file. Use `host.docker.internal` only for integrations listening on the Docker gateway. Loopback-published model services use their private Docker service names.

Imported declaration directories must grant daemon UID10001 read and traverse access while remaining private to the operator and daemon; use named ACLs rather than making the whole backup tree readable. Mount the platform's declared `ai-lab/bot-personas` alongside its `swarm-apps`. Map legacy `OIDC_ISSUER_URL` to native `OSHAL_OIDC_ISSUER` and carry the actual registered client configuration before checking migrated OIDC principals. A minted local session still requires the account issuer to be trusted at request admission.

Local inference needs explicit `OSHAL_INFERENCE_LOCAL_ENDPOINTS` declarations, for example `[{"url_prefix":"http://vllm-fast:8000/v1","addresses":["10.0.0.5"]}]` when that IP (an example address) is the actual provider address on the configured private Docker network. Resolve and pin this deployment's address; do not assume the example matches another machine. The allowance matches the scheme, host, port and path segments, verifies every resolved address and refuses redirects. It applies only to the inference client. Public connector and Finance egress retain their HTTPS/public-address policy.

The read-only `OSHAL_APPLICATION_FILES_IMPORT_DIR` mount contains verified files beneath tenant/application/table/UUID directories. Reserved operator metadata and current SQL relationship policies select visible files. Each invocation snapshots only authorized bytes into its own child, refuses symlinks and traversal, and rechecks authority before returning the response. This boundary serves imported material downloads; it does not grant uploads, external RAG cleanup or access to another user's directory.

## Local model network

Local model services publish to host loopback and share a private Docker network. The kernel joins that existing network through `OSHAL_INFERENCE_NETWORK` and uses service DNS names with explicit address pins in `OSHAL_INFERENCE_LOCAL_ENDPOINTS`. A host-gateway URL cannot reach a service bound only to loopback. Public connector egress retains its original policy; model registration does not establish provider health.

## Local image model

Image generation for applications that declare `media-generation` (for example Portrait Studio and D&D cutaways) runs through the kernel's image executor. Unset `OSHAL_IMAGE_PROVIDER` (or `none`) answers "no image-generation provider is configured". `OSHAL_IMAGE_PROVIDER=comfyui` drives a ComfyUI server at `OSHAL_IMAGE_COMFYUI_URL` through the same fence: the URL, and the optional `OSHAL_IMAGE_COMFYUI_WAKE_URL`, must each match an `OSHAL_IMAGE_LOCAL_ENDPOINTS` declaration, for example `[{"url_prefix":"http://127.0.0.1:8188","addresses":["127.0.0.1"]},{"url_prefix":"http://127.0.0.1:8189/wake","addresses":["127.0.0.1"]}]`; an undeclared address fails boot. `OSHAL_IMAGE_COMFYUI_MODEL`, `OSHAL_IMAGE_COMFYUI_TEXT_ENCODER` and `OSHAL_IMAGE_COMFYUI_VAE` name plain model files (defaults: the Z-Image-Turbo set). Uploaded reference photos and results stay in ComfyUI's temporary folder and each prompt's history entry is deleted after its image is read. The kernel never starts containers: a stopped model is reported as not running, or, with a wake URL, the wake endpoint is asked to start it and the person is told it is starting. A generation must finish within 40 seconds, inside the package's 60-second call deadline.
